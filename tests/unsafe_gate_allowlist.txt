# Unsafe-code inventory for tests/unsafe_gate.rs (U2 gate).
#
# Each line caps one file under the workspace source roots. The gate counts real
# `unsafe {`, `unsafe fn` and `unsafe impl`/`unsafe trait` tokens only (comments
# and string/char/raw literals are ignored), and compares component-wise:
#
#   - a file with unsafe but no entry here fails (new unsafe surface);
#   - a count above the ceiling fails and prints `src/<file>:<line>` for every
#     current site in that file;
#   - a count below the ceiling passes and asks for this file to be tightened.
#
# Every ceiling below is the exact current count, not headroom: there are no
# unused slots for a future block to hide in. The trailing comment names the
# reviewed platform/FFI boundary that justifies the file.
#

# with a `// SAFETY:` note at the site. Do not widen a module/file
# `#[allow(unsafe_code)]` to cover a new block: this gate counts blocks.
